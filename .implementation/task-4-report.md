# Task 4 frontend report

The React/TypeScript workspace serves five ranked challenges from the local API. It has an editable React Flow graph with keyboard forms, revision save/validation, preview/full/experiment runs, SSE progress and cancellation, deterministic requirements and evidence, read-only recorded graph replay, comparison of up to two saved revisions, optional pre-run Hint/Explain and post-run review, and local history/import/export/delete. API types are generated by `npm run generate:api` from `backend/openapi.json`. The UI uses the server's provider availability flag and never invents simulation metrics or guidance.
