## Release measurements

Record hardware/runtime, exact workload, wall time, memory method, date, and command alongside actual results. The target for a full catalogue assessment is 15 cases in at most 60 seconds and at most 2 GiB additional memory. Interaction target is 100 ms; canvas target is 60 fps with investigation above 33 ms p95 frame time. No measurements have been collected yet.

## Manual validation

Live-provider access and the five-person learning study cannot be replaced by deterministic test doubles. Mark each as performed or not performed; do not claim outcomes without observations. Review problem wording, feasibility, feedback and trace evidence for all released challenges.
